Personal portfolio website for **San Shibu**, Full-Stack & Systems Developer.

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: TailwindCSS

Open [http://localhost:3000](http://localhost:3000) to view locally.
